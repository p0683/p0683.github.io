Pikachu靶场搭建实验

Pikachu靶场搭建实验

一、实验介绍

Pikachu（皮卡丘）是面向Web安全初学者的中文漏洞练习平台，源码托管在GitHub。平台内置暴力破解、XSS、SQL注入、文件上传、CSRF、RCE等常见Web漏洞场景，适合在本地可控环境练习渗透测试，学习漏洞原理、利用方式以及修复方案。

二、实验环境

  • 操作系统：Windows
  • Web环境：phpStudy（小皮面板）Apache + MySQL + PHP
  • 靶场地址：http://127.0.0.1/pikachu/index.php

三、搭建步骤

  1. 下载Pikachu源码，解压，将源码文件放到 phpstudy_pro/WWW/pikachu 目录下，不要嵌套多余文件夹，否则访问404。
  2. 打开小皮面板，启动 Apache 和 MySQL 服务。
  3. 修改配置文件 inc/config.inc.php，填写数据库连接信息：
<?php
session_start();
date_default_timezone_set('Asia/Shanghai');
header('Content-type:text/html;charset=utf-8');
define('DBHOST', '127.0.0.1');
define('DBUSER', 'root');
define('DBPW','root');
define('DBNAME', 'pikachu');
define('DBPORT', '3306');
?>
